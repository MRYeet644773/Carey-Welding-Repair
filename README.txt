# Carey Welding & Repair

Website files:
- index.html
- style.css
- script.js

## GitHub Pages
1. Create/open the repository named `JamesCarey.github.io`.
2. Upload all three files to the repository's main/root directory.
3. Go to Settings -> Pages.
4. Set Source to "Deploy from a branch".
5. Select the main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

The quote form opens the visitor's email app. It does not store submissions in a database.
